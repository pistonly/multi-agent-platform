# 三桥协作干净测试

## 来源话题

- topic_id: `69d77715-b2c1-4f85-8d72-188aa452e47b`
- title: 三桥协作干净测试
- discussion_round: `ready`
- round_summary_count: `2`

## 背景

v0.7 P2 已落地 host / participant / reviewer 三条 bridge 与 Cursor SDK runner 接线。本话题经两轮讨论收敛：在**不嵌入 LLM SDK 到 MAP 核心**的前提下，用 `./scripts/start-all-bridges.sh` 做一次端到端 dogfood，验证三 persona 协作链路与本地幂等 state 是否「干净」可复现。

## 目标

1. 三桥（host / participant / reviewer）同时常驻 polling，完成一次完整协作闭环。
2. 验证 host bridge 生命周期：reply_pending → Round Summary ×2 → promote_experiment。
3. 验证 participant bridge 能在 open 话题中按轮次贡献评论。
4. 验证 reviewer bridge 能对 host 创建的实验提交评审（reasonable / unreasonable）。
5. 确认 `.map/*-bridge-state.json` 幂等与重启不重复写入。

## 范围

### 必做

- 使用 `./scripts/start-all-bridges.sh` 启动三桥；日志目录 `.map/bridge-logs/{host,participant,reviewer}.log`。
- host bridge：`scripts/cursor-host-runner.py`，state `.map/host-bridge-state.json`。
- participant bridge：`scripts/cursor-participant-runner.py`，state `.map/participant-bridge-state.json`。
- reviewer bridge：`scripts/cursor-reviewer-runner.py`，state `.map/reviewer-bridge-state.json`。
- 本实验由 host persona 创建并（可选）`MAP_HOST_SUBMIT_REVIEW=1` 提交评审，供 reviewer bridge 消费。
- 记录一次 `--dry-run` 与一次真实 cycle 的差异（仅日志，不改 MAP 核心）。

### 不做

- 不在 MAP API / Web 内嵌 Cursor / OpenAI / Anthropic SDK。
- 不自动 approve / start / complete 实验（保持 human-in-the-loop）。
- 不引入多实例 bridge lease（留待 v0.8）。

## 执行步骤

1. **环境**：API :8001、Web :3000 可用；`.map/` 三 persona token 有效；`pip install cursor-sdk`。
2. **基线**：`map --persona host topic show --id 69d77715-b2c1-4f85-8d72-188aa452e47b` 确认 `discussion_round=ready`、无 pending。
3. **启动三桥**：`./scripts/start-all-bridges.sh`（或分终端启动三个 `start-*-bridge.sh`）。
4. **观察 host 链**：确认本话题已 promote 为本实验；state 中 `last_posted_summary_round=2` 且 promote 不重复。
5. **观察 participant**：确认其在 open 话题中有按轮次评论（Round 1 首次意见、Round 2 聚焦未决项）。
6. **观察 reviewer**：实验进入 review 后，reviewer bridge 生成并提交评审 YAML/JSON。
7. **重启幂等**：Ctrl+C 停止三桥，保留 state 文件后重启，确认无重复 comment / summary / experiment / review。
8. **收尾**：host 记录实验 execution log，更新项目 status_md 叙事（若结论通过）。

## 验收标准

- [ ] 三桥日志可 `tail -f .map/bridge-logs/*.log`，无未捕获异常栈；runner exit code 仅 0/1/2。
- [ ] host bridge 对本话题完成 promote，且 `.map/host-bridge-state.json` 记录 `last_posted_summary_round: 2`。
- [ ] participant 至少 1 条非 host 评论；各 thread 均有 host 回复。
- [ ] reviewer 对本实验提交至少 1 份评审（含 reasonable 与/或 unreasonable 项）。
- [ ] 重启三桥后：重复 polling 周期内**不**重复创建实验、不重复 Round Summary、不重复评审。
- [ ] 实验 execution log 含：执行环境、关键命令、结论、风险与后续动作。

## 风险与回滚

- **CURSOR_API_KEY / 模型不可用**：runner exit 1，bridge 不写 MAP；修复凭证后重试。
- **host 非 creator_agent_id**：experiment create 403；须用 host persona。
- **并发多 bridge 实例**：可能重复写入；本实验仅单实例，文档注明限制。

## 讨论共识摘要

- MAP 管状态与权限；Agent Runtime 管推理；bridge 管 polling、幂等与 persona 写入。
- 验收以「三桥日志可 tail + 全链路一次跑通 + 重启不脏写」为干净测试定义。
- 未决项「多实例 lease」带入后续版本，不阻塞本实验。
