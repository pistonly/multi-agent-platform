# v0.7 P1: Topic discussion_round + advance-round API

## 来源话题

- topic_id: `487491eb-1678-493b-b7cd-f1f3e26ae60c`
- 话题：`v0.7：Topic discussion_round + advance-round API`

## 背景

当前 topic-host 流程依赖评论正文中的 `Round N Summary` 约定，host worker 也需要用正则推断话题是否满足开实验门禁。讨论已收敛：v0.7 P1 应把轮次状态提升为平台可查询字段，同时保持实验创建仍由 host 显式触发。

## 目标

1. 为 `Topic` 增加最小轮次状态：`discussion_round` 与 `round_summary_count`。
2. 提供 host/admin 可调用的 `advance-round` API，推进 `round1 -> round2 -> ready`。
3. CLI 支持推进轮次，`topic show` 输出新字段。
4. Web 话题详情只读展示轮次 badge，不提供 advance 按钮。
5. host worker readiness 改为优先读取字段，减少正文正则推断。

## 非目标

- 不在 `advance-round` 中创建实验。
- 不做 Web advance 按钮。
- 不做 `last_summary_comment_id`。
- 不把 `pending_topic_replies` 作为服务端 advance-round 硬门禁。
- MCP 写入口不纳入 v0.7 P1。

## 设计约束

- `discussion_round`: enum-like value, `round1 | round2 | ready`。
- `round_summary_count`: integer, NOT NULL, default `0`。
- Alembic 使用 NOT NULL + server_default；存量 topic 默认 `round1/0`。
- `advance-round` 权限限制为 topic creator 或 admin。
- 非法跳转返回 409。
- `create_experiment(topic_id)` 对 topic 未 ready 先返回 warning/软提示，不做硬 403。

## 实施步骤

1. 更新模型与 schema：
   - `Topic.discussion_round`
   - `Topic.round_summary_count`
   - Topic read/summary 类型输出新字段
2. 增加 Alembic 迁移：
   - upgrade 添加字段和默认值
   - downgrade 删除字段
3. 增加服务层状态机：
   - `round1 -> round2`
   - `round2 -> ready`
   - `ready` 不再推进
4. 增加 API：
   - `POST /topics/{topic_id}/advance-round`
   - host/admin 权限校验
5. 增加 CLI：
   - `map topic advance-round --id <uuid>`
6. 更新 worker：
   - `_topic_ready_for_experiment` 优先读取 `discussion_round == ready`
   - 正文 `Round N Summary` 正则只作为存量 topic 过渡路径：仅当 topic 缺少新字段，或 `discussion_round=round1` 且 `round_summary_count=0` 时启用
   - 新字段一旦存在且被推进过，readiness 只以 `discussion_round == ready` 与 `round_summary_count >= 2` 为准，避免字段与正文形成双源真相
   - 在 v0.7.1 清理过渡 fallback，届时 worker 不再依赖评论正文正则
7. Web 只读展示：
   - Topic detail 增加轮次 badge
8. 测试：
   - API 权限和状态转换
   - Alembic upgrade/downgrade
   - CLI advance-round
   - worker readiness 字段优先

## 验收标准

- `pytest -q` 通过。
- `ruff check server cli sdk tests` 通过。
- 临时 SQLite `alembic upgrade head` 通过。
- host 可推进自己创建的话题轮次；participant/reviewer 推进返回 403。
- `map topic show` 能看到 `discussion_round` 和 `round_summary_count`。
- ready topic 可由 host 创建关联实验；非 ready topic 返回 warning 而不是阻断。
- worker 测试覆盖两类场景：新字段优先生效；旧正文正则只在存量过渡条件下生效。
